# drill_13

Pico2D 게임 프레임워크 실습을 독립 프로젝트로 분리한 저장소입니다.
로고, 타이틀, 플레이, 정지 모드와 플레이 중 공을 선택하는 아이템 창을 제공합니다.

## 실행

```powershell
python -m pip install -r requirements.txt
python main.py
```

Windows에서는 `py -3`를 `python` 대신 사용할 수 있습니다.
의존성 설치 후 `run.bat`을 실행하거나 이 폴더를 VS Code로 열고 F5를 눌러도 됩니다.
다른 작업 폴더에서 `python 경로/main.py`로 실행해도 이미지 경로가 정상 처리됩니다.

## 조작

| 화면 | 키 | 동작 |
| --- | --- | --- |
| 로고 | 자동 | 약 2초 후 타이틀로 이동 |
| 타이틀 | Space | 새 플레이 시작 |
| 타이틀 | Esc | 프로그램 종료 |
| 플레이 | 왼쪽/오른쪽 방향키 | 캐릭터 이동 |
| 플레이 | Space | 선택한 공 발사; 수면 상태에서는 깨우기 |
| 플레이 | I | 아이템 창 열기/닫기 |
| 아이템 창 열림 | 0 | 공 장착 해제: Space를 눌러도 공을 생성하지 않음 |
| 아이템 창 열림 | 1 | 기본 공 `ball21x21.png` 선택 |
| 아이템 창 열림 | 2 | 큰 공 `ball41x41.png` 선택 |
| 플레이/정지 | P | 정지/재개 |
| 플레이/정지 | Esc | 타이틀로 이동 |
| 모든 화면 | 창 닫기 | 프로그램 종료 |

숫자 키패드의 0/1/2도 지원합니다. 아이템 창이 열려 있어도 게임은 계속 진행됩니다.
선택 행에는 테두리가 표시되며, 창을 닫아도 현재 선택은 유지됩니다.
선택 변경은 이후 발사하는 공에 적용됩니다. 새 플레이는 기본 공과 닫힌 아이템 창으로 시작합니다.

## 구성

- `main.py`: 시작점과 캔버스 관리
- `game_framework.py`: 모드 교체 및 정지 스택
- `logo_mode.py`, `title_mode.py`, `play_mode.py`, `pause_mode.py`: 화면과 상태
- `item_mode.py`: 플레이를 멈추지 않는 아이템 오버레이
- `game_world.py`, `boy.py`, `grass.py`, `ball.py`: 게임 객체와 렌더링
- [PRD.md](PRD.md): 제품 요구사항과 완료 기준
- [docs/VALIDATION.md](docs/VALIDATION.md): 실제 실행 검증 기록
