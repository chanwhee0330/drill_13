# 실행 검증

검증일: 2026-11-09 (한국 시간)

환경: Windows, Python 3.13, 설치된 `pico2d`와 `transitions`.
실제 SDL 캔버스를 열고 화면을 렌더링했으며 프로그램 입력 이벤트로 다음 동작을 확인했다.

| 항목 | 결과 |
| --- | --- |
| 상위 작업 폴더에서 시작한 `main.py`의 이미지 경로와 로고/타이틀 표시 | 확인 |
| Space로 플레이 진입, Esc로 타이틀 복귀 | 통과 |
| I로 아이템 창 열기/닫기 | 통과 |
| 창이 닫혀 있을 때 숫자 선택 무시 | 통과 |
| 0 선택 후 Space를 눌러도 공이 추가되지 않음 | 통과 |
| 1과 2로 각각 제공된 기본 공/큰 공 이미지 선택 | 통과 |
| 공 선택을 바꿔도 이미 발사된 공은 기존 크기 유지 | 통과 |
| 숫자 키패드로 아이템 선택 | 통과 |
| 아이템 창이 열린 동안 캐릭터와 공의 위치 계속 갱신 | 통과 |
| 아이템 창을 연 상태에서 P로 정지하면 객체와 애니메이션 정지 | 통과 |
| 다시 P로 기존 객체의 움직임과 아이템 선택 유지 | 통과 |
| 정지 중 방향키를 놓으면 재개 후 이동 고착 방지 | 통과 |
| 타이틀 복귀 후 새 플레이에서 객체 중복 없이 기본 선택으로 초기화 | 통과 |
| 종료 시 월드, 아이템 이미지와 캔버스 정리 | 통과 |

파일명과 실제 PNG 크기는 다를 수 있다. 제공된 공 이미지의 실제 크기는 각각 23 x 23,
43 x 43이며 검증은 해당 파일을 실제로 불러왔는지 확인했다.

`run.bat` 더블클릭과 VS Code F5는 이 검증에서 직접 조작하지 않았다.
두 설정은 동일한 `main.py`를 실행하도록 구성되어 있다.
